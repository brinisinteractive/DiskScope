# DiskScope

A disk space analyser for Windows. Scan a drive and see exactly what is using
the space — as a sortable tree, a treemap and charts — then clear out what you
don't need.

**[Download the latest version](../../releases/latest)**

---

## What it does

- **Fast parallel scanning** with live totals while it works
- **Treemap** — the whole drive as one picture, coloured by file type, age or size
- **Duplicate finder** — groups by size, then by content hash
- **Snapshots and comparison** — see what changed on a drive since last time
- **Reports** — export to HTML, XLSX, CSV or JSON
- **Safe deletion** — Recycle Bin by default; Windows and program folders refused

Windows 10 and 11, 64-bit.
